# Purple Crown Financial — Homepage

Static homepage for Purple Crown Financial. Deployed via Vercel.

## Files
- `index.html` — standalone static homepage (dev preview)
- `styles.css` — scoped styles
- `ghl-homepage.html` — single-file, GHL-ready embed version
- `assets/` — logo and crown image

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static server.
